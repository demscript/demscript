### 🧠 Who I Am

I'm an **offensive security engineer and penetration tester** — my primary work is finding vulnerabilities in production systems before attackers do, and delivering findings that engineering teams can actually act on.

I've run **authorized penetration tests and vulnerability assessments** across mobile banking apps, payment APIs, fintech platforms, insurance systems, and enterprise infrastructure. I understand the attack surface from both sides: I've built these systems, so I know exactly where to look.

That engineering background isn't my main act — it's what makes my security work sharper. When I flag a vulnerability, I know what remediation costs the dev team, and I write my reports accordingly.

- 🛡️ **VAPT engagements** across fintech, banking, insurance, and enterprise clients
- 📱 **Mobile app pentesting** — Android & iOS, including Flutter-based banking apps
- 🔌 **API security testing** — REST, payment gateways, authentication flows
- 🏢 Clients across **finance, fintech, EdTech, healthcare, and e-commerce**
- ⚙️ I write production code too (Laravel, Flutter) — it makes me a better attacker
- 🌱 Always chasing new attack techniques, TTPs, and CVEs
- 🎮 Outside work: hiking, open source, and strategy games *(gaming levels: fluctuating 😜)*

> *Trying to know how your system holds up under attack? Let's talk.*
